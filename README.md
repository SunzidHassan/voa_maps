# 26_cognitiveOSL_code

## 🚀 Getting Started
### 1. Requirements

We recommend setting up a python virtualenv or conda environment to help manage dependencies. Our code has been tested primarily with Python 3.10.

Sample instruction for `conda` users.
```bash
conda create --name sosl python=3.10
conda activate sosl
pip install -r requirements.txt
```

### 2. Running the Program
#### Running the Experiments

To execute the navigation and search algorithms, run the following command:

```bash
python sOSL_main.py
```

#### Output Directory Structure
Upon execution, a `save` directory is generated containing experimental results. The sub-directories are organized by algorithm type and environment, following the naming convention `save_[Algorithm]_[Environment]`:

| Directory | Algorithm | Environment | Description |
| :--- | :--- | :--- | :--- |
| `save_F_M` | **F**usion (Proposed) | **M**icrowave (Kitchen) | Trajectories generated by the proposed algorithm. |
| `save_F_T` | **F**usion (Proposed) | **T**oilet | Trajectories generated by the proposed algorithm. |
| `save_O_M` | **O**lfactory-Only | **M**icrowave (Kitchen) | Trajectories generated by the olfactory-only baseline. |
| `save_O_T` | **O**lfactory-Only | **T**oilet | Trajectories generated by the olfactory-only baseline. |
| `save_R_M` | **R**andom-Walk | **M**icrowave (Kitchen) | Trajectories generated by the random-walk baseline. |
| `save_R_T` | **R**andom-Walk | **T**oilet | Trajectories generated by the random-walk baseline. |

#### Experimental Configuration

For the **Kitchen environment**, the experiments were conducted using the following parameters:

* **Entropy Fractions:** We evaluated parameter values of `0.704`, `0.8`, and `0.9` for the Kitchen environment, and `0.4`, `0.5`, and `0.6` for the Toielet environment.
* **Starting Positions:** For each parameter value, the algorithm was tested across **16 distinct starting positions**.

## Data Logging

The data saved for each run depends on the complexity of the algorithm:

* **Proposed Algorithm (Fusion):** Saves the robot's egocentric visual frames, detected object maps, probability distributions, environmental knowledge, trajectory logs (`.csv`), and trajectory plots.
* **Olfactory-Only:** Saves the olfactory probability distribution, trajectory logs (`.csv`), and trajectory plots.
* **Random-Walk:** Saves the trajectory logs (`.csv`) and trajectory plots.

For examples of the output formats and directory hierarchy, please refer to the `sampleSave` directory.
